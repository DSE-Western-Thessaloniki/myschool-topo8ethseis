# Προετοιμασία

Το πρόγραμμα λειτουργεί παράλληλα με μια εγκατάσταση browserless/chrome για να
μπορεί να εμφανίζει ιστοσελίδες και να εκτελεί τις κινήσεις μέσω του puppeteer.

## Εγκατάσταση browserless/chrome

Αρκεί να τρέξουμε την παρακάτω εντολή σε ένα τερματικό:

```
docker run -e "CONNECTION_TIMEOUT=-1" -p 3000:3000 --restart always -d --name browserless browserless/chrome
```

Η μεταβλητή περιβάλλοντος CONNECTION_TIMEOUT ορίζει τον χρόνο εκτέλεσης του κάθε
script σε millisecond. Δίνοντας την τιμή -1 λέμε ότι δεν θέλουμε να γίνεται
τερματισμός μετά από κάποιο χρόνο (χρήσιμο ειδικά για λειτουργίες που απαιτούν
πολύ χρόνο). Προσοχή μόνο στον αριθμό των ταυτόχρονων συνδέσεων γιατί κάθε
μία θα δεσμεύει πόρους από το μηχάνημα.

## Εγκατάσταση βιβλιοθηκών

Για τις απαραίτητες βιβλιοθήκες αρκεί να τρέξουμε

```
npm ci
```

## Μεταγλώττιση typescript

Για την μεταγλώττιση της typescript σε javascript αρκεί να τρέξουμε

```
npm run compile
```

ή αν θέλουμε να γίνεται αυτόματα μεταγλώττιση καθώς κάνουμε αλλαγές

```
npm run watch
```

## Αρχείο ρυθμίσεων

Θα πρέπει να δημιουργηθεί ένα αρχείο .env που θα περιέχει τους κωδικούς για την
πρόσβαση στο σύστημα. Αυτό μπορεί να γίνει αντιγράφοντας το παράδειγμα και
συμπληρώνοντας τα αντίστοιχα πεδία.

```
cp .env.example .env
```

# Εκτέλεση

Για να γίνει οποιαδήποτε τοποθέτηση/διάθεση χρειάζονται τα δεδομένα να περαστούν
σε ένα xlsx αρχείο το οποίο θα αποθηκευτεί στην βάση του project με όνομα
`file.xlsx`. Μπορούμε να χρησιμοποιήσουμε το πρότυπο αρχείο `template.xlsx`
μέσα στο οποίο στο φύλλο "Πρότυπο" έχει την μορφή των δεδομένων που απαιτούνται.
Την στήλη ώρες την συμπληρώνουμε μόνο όταν θέλουμε να γίνει διάθεση για μέρος
των ωρών του εκπαιδευτικού. Αν παραμείνει κενή θα χρησιμοποιηθεί το σύνολο των
ωρών του. Το πρόγραμμα πάντα κοιτάει το πρώτο φύλλο του excel ότι όνομα και να έχει
αυτό και περιμένει να βρει τις στήλες με τα συγκεκριμένα ονόματα που φαίνονται
και στο πρότυπο. Μετά την προετοιμασία του αρχείο και την αποθήκευσή του μέσα στον
φάκελο εκτελούμε:

```
npm run start
```

Το πρόγραμμα εκτελείται και εμφανίζει στην κονσόλα μηνύματα για τις κινήσεις που
εκτελεί. Στον φάκελο img αποθηκεύεται ένα στιγμιότυπο οθόνης πριν από την
αποθήκευση κάθε τοποθέτησης για έλεγχο. Επίσης στο αρχείο `down.log` αποθηκεύει
την έξοδο των μηνυμάτων που βλέπουμε και στο τερματικό αν χρειαστεί να ανατρέξουμε
σε αυτό αργότερα.

# Διεπαφή ελέγχου

Μαζί με την εκτέλεση, το πρόγραμμα σερβίρει μια διεπαφή στον browser που δείχνει
ζωντανά τι γίνεται:

- **Ζωντανή προβολή** της σελίδας που ελέγχεται (μέταδοση καρέ από τον
  απομακρυσμένο φυλλομετρητή).
- **Πίνακα προόδου** με κάθε γραμμή του xlsx αρχείου, την κατάσταση της
  (αναμονή / σε εκτέλεση / ολοκληρώθηκε / σφάλμα) και προεπισκόπηση του
  στιγμιότυπου που αποθηκεύτηκε.
- **Καταγραφή** με όλα τα μηνύματα της κονσόλας σε πραγματικό χρόνο.
- **Κουμπιά Εκκίνηση / Διακοπή** για να ξεκινάμε και να διακόπτουμε την εργασία
  χωρίς τερματικό.

## Χρήση

```
npm run ui
```

Ανοίγει μόνο η διεπαφή στο <http://localhost:8787> και η εργασία ξεκινά με το
κουμπί «Εκκίνηση».

```
npm run start
```

Ανοίγει η ίδια διεπαφή αλλά η εργασία ξεκινά αυτόματα (όπως λειτουργούσε το
πρόγραμμα πριν). Μπορεί να σταματήσει με το κουμπί «Διακοπή».

Όταν τρέχει μέσα στο devcontainer, το VS Code προωθεί αυτόματα την θύρα 8787
(δες το `forwardPorts` στο `.devcontainer/devcontainer.json`), οπότε αρκεί να
ανοίξουμε την διεπαφή από τον browser του μηχανήματος μας.

## Ρυθμίσεις

Στο αρχείο `.env` μπορούν να οριστούν:

| Μεταβλητή | Περιγραφή |
| --- | --- |
| `UI_PORT` | Θύρα της διεπαφής (προεπιλογή: 8787) |
| `AUTO_RUN` | `false` για να μην ξεκινά αυτόματα η εργασία (ίδιο αποτέλεσμα με την επιλογή `--no-run`) |
| `BROWSER_WS_ENDPOINT` | Endpoint του browserless (προεπιλογή: `ws://host.docker.internal:3000`) |
